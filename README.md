# Plana

> **Vote, plan, and hangout --- together.**

Plana is a modern social planning and hangout app designed to make it
easier for people to discover plans, vote on activities, coordinate with
friends, and keep everything organized in one place.

The app focuses on turning the process of deciding **what to do, where
to go, and when to meet** into a simple, collaborative experience.

## Overview

Plana brings social planning into a single, focused space. Instead of
relying on scattered chats and multiple apps to organize a hangout,
users can create and coordinate plans, involve friends in decisions, and
keep track of upcoming activities.

The landing experience uses a dark, premium visual style with a
photo-driven hero section that communicates the social and adventurous
nature of the product.

### Core Value Proposition

**Vote. Plan. Hangout. Together.**

Plana is built around three simple actions:

-   **Vote** --- Let friends participate in decisions and choose what
    everyone wants to do.
-   **Plan** --- Organize the details of a hangout or event in one
    place.
-   **Hangout** --- Turn the plan into a real-world experience with the
    people who matter.

## Key Features

-   **Social planning** --- Create and organize group plans and
    hangouts.
-   **Collaborative voting** --- Allow participants to vote on options
    before making a decision.
-   **Hangout organization** --- Keep important event details together.
-   **Simple onboarding** --- Clear sign-up and login entry points for
    new and returning users.
-   **Visual-first experience** --- Photo-based cards and an
    editorial-style interface make plans feel engaging.
-   **Mobile-focused design** --- Designed with a polished mobile
    experience in mind.
-   **Centralized planning** --- Reduce the need to coordinate plans
    across multiple chat threads and applications.

## User Experience

The Plana landing page introduces the product with a visual collage of
travel, sunset, and social scenes. A central event card reinforces the
planning concept with details such as location, date, and the type of
hangout.

The interface then presents the product message:

> **Vote, plan, and hangout together.**

A short supporting statement communicates the goal of keeping users'
plans, people, and activities together in one place.

## Design Direction

Plana uses a **dark, cinematic interface** intended to feel social,
modern, and premium.

### Visual characteristics

-   Dark charcoal/black background
-   Bright blue accent color for calls to action
-   Rounded image cards
-   Large, bold typography
-   Minimal interface elements
-   High-contrast buttons
-   Photo-driven storytelling
-   Mobile-first composition

The design is intended to feel less like a traditional calendar or
productivity application and more like a modern social product.

## Suggested Product Flow

A typical Plana experience can follow this flow:

1.  **Sign up or log in**
2.  **Create or discover a hangout**
3.  **Invite friends**
4.  **Add possible activities, locations, or dates**
5.  **Let participants vote**
6.  **Finalize the plan**
7.  **Meet up and hang out**
8.  **Keep the completed or upcoming plan available for reference**

## Project Goals

Plana aims to solve a common social problem: **making plans is often
harder than actually going out.**

By combining voting, planning, and social coordination, the app can help
groups:

-   Make decisions faster
-   Give everyone a voice
-   Avoid long and confusing chat conversations
-   Keep event information organized
-   Make spontaneous hangouts easier to coordinate
-   Turn ideas into confirmed plans

## Getting Started

If Plana is being developed with a modern JavaScript frontend such as
React and Vite:

``` bash
# Clone the repository
git clone <repository-url>

# Enter the project directory
cd plana

# Install dependencies
npm install

# Start the development server
npm run dev
```

Then open the local development URL provided by the development server.

## Environment Variables

If the project uses external services or APIs, create a `.env` file and
add the required variables.
